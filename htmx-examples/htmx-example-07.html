Boosting standard links

This page uses hx-boost="true" on the body tag. This means all standard links and forms will be converted to AJAX requests.

Click the links above. Watch the browser tab title and URL change, but notice the page doesn't do a full refresh (flash).

What happens?

  • Links become AJAX requests automatically
  • Forms submit via AJAX
  • Only the target container is replaced
  • The browser history still works
  • Progressive enhancement: if htmx isn’t loaded, everything works normally
